# Program/Rule Example

`data/programs/*.yaml` stores public program facts and source references.

`data/rules/2025-property-tax-relief.yaml` stores cross-program filing-path vocabulary and special-case triggers.

Python evaluation logic is intentionally small and conservative. It determines only simplified candidate status. Complex ownership, estate, trust, P.I.L.O.T., multi-unit, continuing-care, and prior Senior Freeze base-year cases must be escalated to official NJ guidance.
