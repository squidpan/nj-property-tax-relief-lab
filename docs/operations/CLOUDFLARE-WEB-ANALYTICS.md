# Cloudflare Web Analytics

## NJ Property Tax Relief

- Cloudflare Pages project: `nj-property-tax-relief-lab`
- Production branch: `main`
- Production Pages URL: `https://nj-property-tax-relief-lab.pages.dev`
- Automatic deployments from GitHub `main`: enabled
- Cloudflare Web Analytics: enabled
- Analytics activation requires a deployment after enabling Web Analytics in the Cloudflare dashboard.

## Activation procedure

1. Open the Pages project in Cloudflare.
2. Open the `Metrics` tab.
3. Scroll to `Web Analytics`.
4. Click `Enable`.
5. Confirm Cloudflare reports that Web Analytics is enabled.
6. Trigger a new production deployment from GitHub `main`.
7. Verify the new production deployment succeeds.
8. Open `View Web Analytics` and confirm the analytics property is active.
