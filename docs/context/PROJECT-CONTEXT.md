# Project Context

## Why this project exists

This project is Experiment 0 in a broader effort to test whether small, useful, software-backed information assets can attract search traffic and later support legitimate monetization.

The immediate experiment is New Jersey property-tax-relief guidance because the topic is timely, rule-driven, action-oriented, and suitable for a lightweight decision aid.

## What this project is not

This project is not:

- the State of New Jersey;
- a tax-preparation service;
- an eligibility determination service;
- a filing service;
- a repository for personally identifying or financial data.

## Product principle

Save the visitor time while preserving a clear path back to authoritative NJ government sources.

## Engineering principle

Use the simplest architecture that satisfies the present requirement. Preserve a clean evolution path toward a fuller Python/FastAPI/PostgreSQL application only if later requirements justify it.
